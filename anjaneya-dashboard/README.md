# EventFlow Pro

Redesign the UI/UX of this React + Vite event management dashboard without changing its functionality, routing, business logic, API integrations, or file structure.

The goal is to create a premium, modern SaaS dashboard suitable for a national-level hackathon.

Design style:

- Minimal

- Glassmorphism where appropriate

- Clean spacing

- Rounded cards

- Soft shadows

- Excellent typography

- Professional color palette

- Smooth animations

- Responsive on mobile, tablet and desktop

Inspiration:

- Linear

- Notion

- Vercel

- Stripe Dashboard

- Supabase

- Clerk

Requirements:

1. Dashboard

- Premium analytics cards

- Beautiful charts

- Hero overview section

- Recent activities

- Upcoming events

- Volunteer overview

- AI insights card

- Quick actions

2. Sidebar

- Modern collapsible sidebar

- Animated icons

- Active page indicator

- Better spacing

3. Navigation

- Sticky top navbar

- Search bar

- Notifications

- User profile

- Dark mode toggle

4. Cards

- Consistent design

- Hover animations

- Loading skeletons

- Better spacing

5. Tables

- Modern tables

- Search

- Filters

- Pagination

- Status badges

6. Forms

- Multi-step where appropriate

- Better validation UI

- Icons
