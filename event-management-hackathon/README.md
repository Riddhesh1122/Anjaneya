# event-management-hackathon

Starter scaffold for a college event management hackathon project.

Structure

```
event-management-hackathon/
├── package.json
├── .gitignore
├── README.md
├── public/
├── src/
└── .env.example
```

Quick start

```bash
cd event-management-hackathon
npm install
npm run dev
```

Open `http://localhost:3001` (default)
